# OLI Sözleşmeler v0.5.7.1 — One Click Revision

## Ürün akışı
Sözleşmeyi yükle → ⚡ Otomatik Revize Et → Revize Word'ü indir.

## İlke
OLI, bildiği ve Rule Library / Madde Bankası ile desteklenen temel revizyonları kullanıcıya tek tek sormadan uygular.
Kullanıcı aynı metni uygulamada ikinci kez okumak zorunda bırakılmaz.

## Güvenlik
- Eksik ücret, tarih, sayı, isim vb. veri uydurulmaz; boş/eksik alan olarak işaretlenir.
- Risk/dikkat noktaları Word üzerinde işaretlenmeye devam eder.
- Yeni/standart dışı hükümler Word üzerinde ayırt edilir.
- MICRO → PHRASE → BLOCK drafting yaklaşımı korunur.
- Gelen sözleşmenin cümle yapısını mümkün olduğunca koruma ilkesi devam eder.

## Korunanlar
- Word / Track Changes motoru
- Sarı doldurulması gereken alanlar
- Risk/dikkat ve yeni hüküm işaretleri
- Karşı Taraf Dönüşü
- Madde Bankası
- Rule Library
- Arabuluculuk

## Kaldırılan / devre dışı bırakılan yaklaşım
- Learning Engine yoktur.
- Toplu öğrenme yoktur.
- Nihai revizyondan öğrenme yoktur.
- Normal akışta tek tek revizyon kabul/red zorunluluğu yoktur.
