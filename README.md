# Opus Legal Intelligence v0.1
İlk çalışan arayüz prototipi.

## Çalıştırma
1. Python 3.11+ kurulu olmalı.
2. Klasörde terminal açın.
3. `pip install -r requirements.txt`
4. `streamlit run app.py`

Tarayıcıda açılan yerel adres üzerinden çalışır. Şimdilik yalnızca ACTOR_TV_MAINSTREAM Rule Library ve belge yükleme arayüzü aktiftir; gerçek belge ayrıştırma ve AI analizi sonraki adımdır.
